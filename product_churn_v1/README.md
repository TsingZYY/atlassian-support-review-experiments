# 五个产品：谁更容易流失？

**本轮结论：数据不能给出可靠的真实流失排名。取消请求占比在样本中是Loom最高、Confluence最低，但没有显示明确的产品差异。** 5月低使用的产品差异很明显，也不能据此把Loom定义为最容易流失、Jira定义为最难流失。

## 假设与数据

用户提出比较Loom、Trello、Bitbucket、Confluence、Jira的客户流失难易。比赛说明把三张表标注为合成数据，未提供抽样框、抽样权重或生成机制。抽样本身不意味着无法发现规律，但本样本全部客户有工单，不能代表各产品所有客户。

原表没有取消成功、订阅终止、未续费或明确的churn标签。因此，把可检验假设收窄为：**产品之间，已记录取消请求的客户占比是否不同？** Ticket Type为Cancellation request作为唯一主指标；使用变化只是单独的辅助观察，不替代真实流失。

主队列保留能一致关联的8,181个客户，每客户仅一个合格产品；139个身份冲突客户涉及261个客户—产品组合，被排除。取消请求分析没有因使用值异常剔除客户。使用分析另排除59个使用记录不合法的客户，分母为8,122。分产品排除数和原始CSV哈希均在[results.json](results.json)。

## 观察结果

| 产品 | 取消请求人数／主分母 | 取消请求占比 | 5月低使用人数／使用分母 | 5月低使用占比 | 持续显著下降占比 |
|---|---:|---:|---:|---:|---:|
| Loom | 340 / 1,586 | 21.44% | 318 / 1,584 | 20.08% | 1.89% |
| Trello | 324 / 1,575 | 20.57% | 155 / 1,569 | 9.88% | 1.66% |
| Bitbucket | 297 / 1,535 | 19.35% | 131 / 1,516 | 8.64% | 1.39% |
| Confluence | 335 / 1,767 | 18.96% | 188 / 1,755 | 10.71% | 1.54% |
| Jira | 338 / 1,718 | 19.67% | 114 / 1,698 | 6.71% | 1.88% |

5月低使用定义为当月活跃率低于10%。持续显著下降定义为4、5月均较1—3月个人平均活跃率相对下降至少30%、且绝对下降至少10个百分点。前者衡量使用水平，后者衡量相对自身过去的变化；两者都不是流失标签。

## 验证告诉了我们什么

**取消请求没有显示清晰的产品差异。** 五组整体Pearson检验p=0.394。Loom与Confluence的样本差距为2.48个百分点；比较全部10对产品并作Holm校正后，这个极端对比p=0.739，没有任一对得到明确差异支持。不能把“没有检出差异”解释为所有产品必然相等。

按主队列8,181人的共同套餐构成标准化后，取消请求占比分别约为Loom21.41%、Trello20.53%、Bitbucket19.42%、Confluence18.96%、Jira19.64%；套餐内置换的整体范围检验p=0.397。所有产品—套餐单元都有样本，最小单元222人。使用共同队列8,122人的独立敏感性分析同样未显示清晰差异；其套餐调整结果使用该共同队列权重，p=0.340，不能与主队列混用。

**低使用差异不等于流失差异。** Loom低使用占比20.08%，Jira为6.71%；但1—3月平均活跃率原本就分别约22.58%和32.79%。这是与原有使用频率差异相容的现象，不能证明原因来自产品本身。采用相对个人历史的持续下降指标后，Loom为1.89%，Jira为1.88%，五产品整体p=0.756。

记录中没有“前三月有使用、随后4月和5月都零使用”的客户。该常数指标不能进行产品差异检验，p值标为不适用；更不能据此声称真实流失率为0。

统计区间和p值只反映把当前合成样本视作相应可交换观测时的计算不确定性，不能覆盖未知生成机制、支持客户筛选偏差及真实产品市场差异。套餐调整也不建立产品导致流失的因果关系。

## 研究闭环与决定

产品流失假设 → 核对是否有流失标签 → 以原字段定义取消请求和使用代理 → 使用各自完整分母比较 → 复核统计与20条来源案例 → 限定结论。

本轮保留流失预防作为项目目标，但**不采用“Loom最易流失／Jira最难流失”等未经数据支持的结论**。目前可陈述的洞察是：不同产品的绝对使用水平存在差异，统一低使用阈值可能混入产品原有使用频率，因此它不能直接承担跨产品流失排名的含义。是否需要不同复核基线可另提假设，本轮未证明任何干预能降低流失。
