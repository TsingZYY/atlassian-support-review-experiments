# 集成使用是否与套餐最相关？

**验证支持一个明确结论：在比赛合成数据的五项使用指标中，集成使用量与套餐类别的单变量关联明显最强。R²超过50%可以在明确模型方向下得到；为什么有人少用集成、增加使用是否促进升级或利润，数据尚不能回答。**

## R²到底验证了什么

套餐是类别。本轮用套餐的四个组均值预测集成数量，等价于含截距和套餐独热变量的OLS；R²等于套餐组间方差占总方差的比例（eta²）。**解释方向为套餐类别→集成使用数量**，不是“集成解释了87.9%的套餐变更”，也不是因果贡献。截图未给出原始模型、聚合或代码，所以只能核实该清晰定义下的判断，不能声称逐项复现对方模型。

| 计算口径 | 分母 | R² |
|---|---:|---:|
| 原始客户×产品×月份记录，仅描述 | 42,210行 | 59.14% |
| 每客户跨产品、五个月平均集成数，主分析 | 8,320人 | 87.93% |
| 训练客户拟合套餐均值，预测另一组客户 | 1,666名测试客户 | 87.26% |

主R²的2,000次套餐内客户重抽样95%区间为 **87.56%—88.31%**。2,000次客户套餐标签置换没有一次达到该强度，使用加一修正的探索性p=0.000500；这个值受重复次数分辨率限制，不能写为p=0。

原始行与客户均值是不同尺度：取五个月均值减少客户月度波动，R²升高并不意味着任何干预提升了效果。没有把42,210行当独立客户做显著性检验。每个月独立展示的描述性R²也为58.26%—59.87%，不用选择某个特别月份才能超过50%。

客户ID固定哈希划分为训练6,654人、测试1,666人，同一客户全部记录只在一侧。训练中只拟合四个套餐均值；测试均方误差0.34967，训练全局均值基线误差2.74577。该结果是同一合成数据内的泛化检查；数据已被探索，且没有套餐历史，不能称为未来升级预测或真正外部验证。

## “最重要”应限定为已比较的五项关联

使用相同的8,261名合格客户，各指标都先按客户对全部产品月记录取平均。Active Days按每月日历天数标准化；85条活跃天数越界记录涉及59人，这59人只从五指标共同队列排除，仍保留在集成主分析。

| 使用指标 | 套餐组别解释其差异的R² |
|---|---:|
| 集成使用量 | **87.94%** |
| 会话数 | 18.79% |
| 活跃天数占当月比例 | 18.49% |
| 产品操作数 | 17.86% |
| 协作人数 | 10.15% |

集成R²比其他四项中的最大值高 **69.15个百分点**；同一客户配对重抽样的95%区间为67.78—70.41个百分点，差距清晰。五个产品分别重复计算，集成R²都在 **87.53%—88.15%**，结果不是仅由某一个产品带动。

因此可说“集成在这五项指标中与套餐的单变量关联最强”。没有拟合包含所有人口特征、产品和使用量的套餐分类模型，不能把本排名称作全因素独立贡献、商业价值排名或最重要的升级原因。

## 套餐之间的实际差异

| 套餐 | 客户数 | 客户平均集成数 | 至少一条产品月记录为0 | 五个月、全部产品记录均为0 |
|---|---:|---:|---:|---:|
| Free | 1,472 | 1.14 | 1,299 | 4 |
| Standard | 3,309 | 2.40 | 1,095 | 0 |
| Premium | 2,337 | 4.10 | 30 | 0 |
| Enterprise | 1,202 | 5.99 | 0 | 0 |

“客户平均集成数”先平均客户全部产品月的Integrations Used，再对客户等权平均；它不是去重后的集成总数或集成调用次数。

3,979条产品月记录为0，占42,210条的9.43%；2,424名客户曾有零记录。但**真正所有五个月、所有产品都记录为零的只有4/8,320名客户**。因此不能将所有零记录都当成“长期不使用集成的客户”，也不能由一月为零推断客户不知道该功能。

## 为什么不用更多集成：证据仍缺哪一部分

原字典只提供集成使用数量和静态套餐，没有月度套餐变更、套餐可用集成额度、集成尝试/失败、具体需求或不用的原因。高级套餐限制不同、客户需求差异、企业规模或合成数据生成规则，都是可能解释，尚未验证其中任何一个。增加集成使用可能是升级的结果，也可能与升级共同受其他因素影响。

这个方向值得保留为**集成采用情况的分层研究**：以产品和套餐作为比较基线，寻找使用偏低的候选，再核实是否存在需求、配置失败或认知障碍。低于同组均值本身不证明需要干预。当前比赛数据足以展示关联与候选研究方法；关于具体阻碍、采用提升、升级和利润的后续效果均为CANDIDATE-UNRUN，不能填写虚构转化率。

## 已完成的研究闭环与复现

假设来自截图；固定类别套餐的R²方向、客户单位和五指标比较；检查关联、客户重抽样、分产品与客户留出；核对每套餐5人共20条原始来源；据此接受“强关联且在这五项中最强”，保留“不用原因、升级和利润未知”。这是关联研究的闭环，业务干预闭环尚未发生。

输入为比赛[客户表](../data/customers.csv)、[产品使用表](../data/product_usage.csv)与[字典](../data/README.md)。8,320个客户ID唯一且全部匹配；8,442个客户×产品组合各有完整五个月，无重复组合月份。8,202人一个产品、114人两个、4人三个。没有为无关工单身份冲突删人，也没有新增模拟客户或结果。
