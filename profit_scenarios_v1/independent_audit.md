# 独立计算审计

审计结论：通过。四个情景的解析期望、精确概率及成本边界与独立计算一致；100,000 次模拟的偏差处于蒙特卡洛误差范围。此结论只确认条件模型的计算正确，不确认其中任何转化假设真实，也不确认真实利润效果。

## 独立性与范围

先读取本轮协议、前轮冻结名单及前轮选择协议，然后直接读取比赛三张 CSV。未读取本轮 `experiment.py`、`results.json` 或 `scenario_summary.csv`，即先完成队列重建、20 人名单重建、秩标准化、四个情景的解析均值及 Poisson-binomial 分布计算。得到独立结果后才读取主实现与输出对照。未使用外部数据或网络；本次审计仅新增本文件。

独立实现采用 Python 标准库 CSV、计数与逐项概率递推。每个客户的增量购买概率为 `q=p1-p0`；对每组 10 人计算增量人数分布，再枚举两个组的计数组合。该方法依赖协议明示的个体购买单调耦合与客户独立性。期望公式本身不依赖这种反事实耦合，利润分布及概率依赖它。

- 各产品候选总体的中位秩变换 `z` 均值均为 0。20 人中优先组均值为 0.9926761169429191，普通组为 −0.0757672806052024。
- 普通名单是前轮固定的同产品剩余池哈希样本，排除了优先名单；本次未重抽。结果条件于这两张固定名单，不能解释为所有普通抽样名单的平均效果。

## 主输出与模拟误差核对

- 四个情景中两组及两组之差的期望值与独立结果一致，误差小于 1e-10；精确赚钱概率误差小于 1e-12。
- 保本/亏损概率、中央 95% 模型区间、触达成本边界、筛选成本优势边界与独立结果一致。
- 按独立精确分布方差重新计算均值的蒙特卡洛标准误，12 项模拟均值的最大绝对偏差为 1.134 个标准误。
- 按精确 Bernoulli 概率重新计算赚钱概率的蒙特卡洛标准误，12 项模拟概率的最大绝对偏差为 0.907 个标准误。
- 全部 300 行贡献/触达/筛选成本网格均以独立求得的增量转化期望重新计算，误差小于 1e-10。

## 结论边界

该模型清楚地区分了“触达后更会购买”和“触达造成更多购买”。自然购买反例与正向情景有完全相同的触达后转化概率，但前者两组均亏损，是必要且有效的反例。实际应属于哪个世界、自然转化率、个体触达效应、净贡献、触达成本及筛选成本都没有从比赛数据得到估计。100,000 次重复降低计算噪声，不增加真实客户证据量。
